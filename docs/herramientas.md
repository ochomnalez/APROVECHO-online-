## Reglas de uso

1. **Logo, íconos y cualquier pieza con texto se hacen en código** (SVG/HTML), no con IA: es exacto, editable, escalable y no consume créditos externos. La IA (Recraft Vector) se usa, como mucho, para explorar ideas.
2. **Fotos de comida, comercios y personas** (landing, app, videos): ElevenLabs. Para foto realista, Nano Banana Pro o GPT Image 2.5; para combinar con texto, Ideogram.
3. **Clips de video:** ElevenLabs (Veo 3.1, Kling 4 o Seedance 2.5). **Voz en off y música:** ElevenLabs. **Montaje final:** Remotion.
4. **Costos:** cada generación consume créditos de **ElevenLabs** (o de Higgsfield), no de Claude. Claude gasta solo en escribir los prompts y revisar los resultados.
5. **Antes de generar:** pedir OK al usuario con la cantidad de piezas y el modelo. No repetir generaciones para "reintentar".
6. Centralizar en **ElevenLabs** para tener una sola billetera, salvo que se compren créditos de Higgsfield.
