# Mensaje para mandarle a Facundo (por WhatsApp)

Facu, te sumé al proyecto de APROVECHO. Para empezar:

1. Aceptá la invitación al repositorio (te llega por mail de GitHub, o con el link que te pasé).
2. Entrá a **claude.ai/code** con tu cuenta, conectá tu GitHub si te lo pide y elegí el repositorio **ochomnalez/APROVECHO-online-** (rama `claude/gallant-planck-ps6te6`).
3. En el chat escribí exactamente esto:

> **Hola, soy Facundo. Octavio me pidió que me muestres la bienvenida.**

El chat te va a explicar el proyecto y te va a guiar paso a paso para conectar las aplicaciones de video. No tenés que saber nada técnico: lo guarda todo solo.

Si algo no se parece a lo que ves, mandame una captura.
