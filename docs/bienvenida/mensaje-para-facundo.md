# Mensaje para mandarle a Facundo (por WhatsApp)

Facu, te sumé al proyecto de APROVECHO (videos, landing y app). Usás Gemini, así que lo más fácil es trabajar **desde el navegador, sin instalar nada**:

1. Aceptá la invitación al repositorio (te llega por mail de GitHub).
2. Abrí el repo: https://github.com/ochomnalez/APROVECHO-online-
3. Tocá el botón verde **Code** → pestaña **Codespaces** → **Create codespace on branch** y elegí la rama `claude/gallant-planck-ps6te6`. Se abre un editor en el navegador (tiene una terminal abajo).
4. En la terminal de abajo escribí estos dos comandos, uno por vez:
   `npm install -g @google/gemini-cli`
   `gemini`
   (la primera vez te pide entrar con tu cuenta de Google).
5. Cuando abra el chat de Gemini, escribí exactamente:

> **Hola, soy Facundo. Octavio me pidió que me muestres la bienvenida.**

Gemini te va a explicar el proyecto y te va a guiar paso a paso, incluso con las aplicaciones de video. No necesitás saber de GitHub: él lo guarda todo en una rama tuya.

Si algo no se parece a lo que ves, mandame una captura.
