# APROVECHO — Proyecto digital

> "Menos desperdicio, más aprovecho"

APROVECHO conecta comercios de comida que tienen excedentes en buen estado con consumidores cercanos que los compran en packs a mitad de precio. Con los datos de cada operación ayuda al comercio a medir y reducir su desperdicio.
