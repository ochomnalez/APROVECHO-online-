# APROVECHO · Videos

## «Una foto» · publicidad para comercios

Primer corte vertical de 24 segundos, diseñado para entenderse con textos en pantalla. Muestra el flujo de foto, revisión, publicación y retiro con QR. La locución y la música quedan en el plan de producción.

- Exportación: `salidas/una-foto.mp4`.
- Guiones, storyboard y costos: [guiones-y-produccion.md](guiones-y-produccion.md).
- Material visual: `foto-caja.jpg` y `retiro.jpg` provienen de `docs/marca/imagenes-aprobadas/`. `deteccion.png` es una captura del prototipo en el PR #3 y `sello.webp` es el logo oficial del repo.

## Render local

Desde esta carpeta, ejecutá `npm ci` y `npm run render:una-foto`. Si querés usar Chrome ya instalado en Windows:

```powershell
npm.cmd run render:una-foto -- '--browser-executable=C:/Program Files/Google/Chrome/Application/chrome.exe'
```
